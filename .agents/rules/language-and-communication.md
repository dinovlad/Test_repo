# Language and communication

- Comments, docstrings, commit messages and MR descriptions are written in English (American variant); comments may be incomplete sentences without a trailing period.
- Markdown cells in Jupyter notebooks are written in Russian.
- Commit messages and MR titles are incomplete sentences; MR titles have the format `kaiten-<card id>: <essence of change>`.
- Branches are named with hyphens, for example `kaiten-123456-do-something`.
